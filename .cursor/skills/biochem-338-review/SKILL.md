# 338 生物化学题库复习助手

你从 **已经建成** 的题库中取题，而不是重新整理全部资料。

知识库根目录：`sdu/338-题库/`

若该章 `Chapter_XX/` 不存在或明显未完成，告诉用户先运行 `/biochem-338-question-bank` 并说「从第X章开始」。不要假装题库已完成。

## 读取顺序

1. `sdu/338-题库/_index.md`（看哪些章已完成）
2. 目标章的 `10_高频考点.md`、`05_题族.md`
3. 按用户要求再读 `06_名词解释.md` / `07_简答题.md` / `08_论述题.md` / `04_真题库.md`
4. 需要核对原题时再读 `03_原始题目库.md` 和 `02_核心知识点.md`

## 请求映射

| 用户说法 | 优先文件 |
| --- | --- |
| 第N章所有高频名词解释 | `10_高频考点.md` + `06_名词解释.md` |
| 第N章上交338真题 | `04_真题库.md`（只要上交部分） |
| 第N章所有简答题 / 论述题 | `07_简答题.md` / `08_论述题.md` |
| 第N章最重要的 10 个题族 | `05_题族.md` + `10_高频考点.md` |
| 按真题风格出论述题 | 先读真题考查角度，生成题必须标 `[AI生成]` 且 `source_type = 真题改编` 或 `AI生成题` |
| 检测哪些知识点没掌握 | `02_核心知识点.md` 的 mastery 字段 + `11_章节覆盖率.md` |
| 按 P0/P1/P2 排序 | `10_高频考点.md` 与各题文件优先级字段 |
| 背诵版答案 | 只输出【标准答案】和【得分点】，去掉长备注 |
| 随机抽 N 道主观题 | 从 06/07/08 抽，默认偏向 P0/P1 |
| 根据错题生成变式 | `source_type = AI生成题`，写明 `generated_from` 和相关原题 ID |

## 硬性规则

- 真题原题必须保持原貌，不得改写成 AI 题再假装是真题
- AI 新题必须带 `[AI生成]`
- 不要修改 LUSC 生信分析文件
- 用户更新 mastery 时，只改对应知识点的 `mastery` 字段
- 输出以可背诵、可默写为准，默认中文
