# 核心原则与禁止行为

## 1. 资料优先原则

所有知识点、题目和答案，优先来源于用户提供的资料。

禁止在没有资料依据的情况下擅自扩展考试知识。

如果需要补充教材外知识：

- 必须明确标记为「补充知识」
- 不得伪装成原资料内容
- 不得伪装成历年真题
- 不得伪装成老师原题

## 2. 原题绝对保护原则

任何资料中的原始题目必须尽可能保留原貌。

`source_type` 判定：

| 条件 | source_type |
| --- | --- |
| 资料明确为真题（有年份/学校/考试名/“真题”等证据） | `真题` |
| 课后习题 | `课后题` |
| 资料整理者编写 | `资料题` |
| Agent 根据知识点生成 | `AI生成题` |
| 根据真题考查角度生成相似题 | `真题改编` |
| 其他高校相关生化真题 | `其他院校真题` |
| 只有题目、没有来源信息 | `未知` |
| 文件来源无法确定 | `未确定` |

严禁把 AI 生成题标记为：真题、历年题、课后原题、教材原题。

禁止根据题目风格猜测年份。不要猜。

## 3. 真题权重

```text
上交338真题
> 其他高校相关生化真题
> 课后习题
> 资料整理题
> AI生成题
```

如果存在明确的上海交通大学 338 真题，必须优先分析其考法。

其他学校真题可用于知识点补充、题型参考、考查角度参考，但必须明确标记「其他院校真题」，不能与「上交338真题」混为一谈。

## 4. 防止幻觉

任何答案如果资料无法确认：

- 写「资料未明确给出」
- 或「需要进一步核对教材」

禁止：

- 编造真题年份
- 编造考试学校
- 编造题目来源
- 编造教材页码
- 编造老师观点
- 编造答案来源

## 5. 质量优先级

```text
准确性 > 可追溯性 > 考试价值 > 覆盖率 > 题目数量
```

不是题目数量优先于准确性。

## 6. 禁止行为

Agent 不得：

1. 编造真题
2. 编造年份
3. 编造学校
4. 编造题号
5. 编造资料来源
6. 把 AI 题冒充真题
7. 删除原始题目
8. 用 AI 知识覆盖资料原文
9. 为了凑题量生成大量低质量题
10. 为了达到覆盖率强行生成题
11. 把相同知识点的不同考法全部删除
12. 把不同知识点的相似题目强行合并

## 7. 核心思想

这个 Skill 最重要的不是「生成题」，而是：

> **建立「知识点 → 原题 → 真题 → 题族 → 主观题 → 答案」的可追溯关系。**

任何一道最终训练题，都应该能够回答：

```text
这道题考什么？
↓
来自哪里？
↓
有没有原题？
↓
有没有真题？
↓
属于哪个题族？
↓
为什么值得练？
↓
答案有哪些得分点？
```

如果无法回答这些问题，则降低该题的可信度，并明确标记。

## 8. 终极输出原则

最终题库应该让用户能够做到：

```text
看知识点 → 看原题 → 看真题 → 看题族 → 看主观题 → 背答案 → 做变式题
```

而不是：看一堆 AI 生成的题。

整个系统必须以「上海交通大学 338 生物化学主观题考试的实际备考价值」作为最终评价标准。
