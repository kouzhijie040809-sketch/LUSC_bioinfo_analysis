## 覆盖率检查

每章必须计算：

```text
knowledge_points_total
knowledge_points_with_questions
knowledge_points_with_subjective_questions
knowledge_points_with_answers
```

得到：知识点覆盖率、主观题覆盖率、答案覆盖率。

报告必须列出：

- 未覆盖核心知识点
- 只有客观题覆盖的知识点
- 建议补充（不得为凑覆盖率乱出题）

## 不允许为了提高覆盖率乱生成题

如果一个知识点没有自然的主观题考法：标记 `客观题知识点` 即可。

目标是「核心知识点得到充分主观题覆盖」，不是「100% 知识点都有题」。

## 第一章 / 每章质量检查

完成一章后必须执行：

| Check | 问题 |
| --- | --- |
| 1 | 是否所有相关资料都扫描？ |
| 2 | 是否漏掉题目？ |
| 3 | 是否正确识别真题？ |
| 4 | 是否存在重复题？ |
| 5 | 是否存在错误章节归类？ |
| 6 | 是否有核心知识点没有对应题目？ |
| 7 | 是否有客观题知识点未提取？ |
| 8 | 是否有 AI 生成内容冒充原题？ |
| 9 | 是否有答案缺乏资料依据？ |
| 10 | 是否存在明显事实错误？ |

把结果写入 `processing_log.md`。
