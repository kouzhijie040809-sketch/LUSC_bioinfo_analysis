# 主观题映射与生成

所有知识点最终必须尝试映射到：名词解释、简答题、论述题。

## 映射示例

知识点：蛋白质变性

- 名词解释：什么是蛋白质变性？
- 简答：简述蛋白质变性的概念、原因及结果。
- 论述：论述蛋白质结构稳定性与变性的关系，并分析影响蛋白质变性的主要因素。

## 名词解释生成规则

答案必须：短、准、完整、适合考试书写。

推荐结构：`定义 + 核心特征 + 必要补充`

不要写成教材长篇介绍。默认约 50～150 字，但不要机械限制字数。

## 简答题生成规则

答案优先采用：

```text
定义 → 原理 → 过程 → 结果 → 意义
```

根据具体问题选择其中适用部分。

机制题：

```text
1. 定义
2. 发生条件
3. 作用机制
4. 结果
5. 生物学意义
```

比较题：

```text
1. 共同点
2. 不同点
3. 关键机制
4. 生物学意义
```

## 论述题生成规则

论述题不是简单把简答题变长。应建立完整逻辑链：

```text
背景 → 核心概念 → 机制 → 关键步骤 → 调控 → 相互关系 → 生物学意义
```

如果题目涉及代谢过程，优先：

```text
场所 → 底物 → 关键反应 → 关键酶 → 能量变化 → 调控 → 与其他代谢途径联系 → 生理意义
```

## 主观题库组织

最终主观题库按照考试题型组织：

```text
名词解释
简答题
论述题
```

而不是只按照资料来源组织。

真题必须单独保存在 `04_真题库.md`，绝对不能与 AI 生成题混在一起。

## 主观题去重

生成主观题之后再次去重。

例如：

```text
什么是蛋白质变性？
解释蛋白质变性的概念。
简述蛋白质变性。
```

如果答案和考查目标高度相同：归入同一个题族。

如果考查角度不同：保留。

## AI 生成内容标记

所有 AI 生成内容必须具有 `[AI生成]`。

例如：

```markdown
### [AI生成] 名词解释

什么是 XXX？
```

原题不得添加 `[AI生成]`。

## 不为覆盖率乱生成题

如果一个知识点没有自然的主观题考法：不要为了达到 100% 覆盖率强行生成题目。

标记为 `客观题知识点` 即可。

目标不是「100% 知识点都有题」，而是「核心知识点得到充分主观题覆盖」。
