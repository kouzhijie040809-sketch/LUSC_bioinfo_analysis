# 答案构建

用户最终需要的是考研主观题答案：考试可写，而不是学术论文式完整。

强调：关键词、逻辑、得分点。

避免：不必要的长篇背景、过多拓展、与得分点无关的细节、过度学术化表达。

## 答案来源等级

```text
A：资料中存在明确标准答案
B：教材内容可以直接支持
C：多个资料交叉推导
D：AI整理
E：外部补充
```

优先使用：`A > B > C > D > E`

资料无法确认时：写「资料未明确给出」或「需要进一步核对教材」。

## 资料原文保护

如果原资料存在答案：不要直接修改原答案。

保存：

- `source_answer`：资料原答案
- `exam_answer`：经过整理、适合考试书写的版本

## 答案压缩

如果资料答案过长，允许：压缩、重组、去除非得分信息、增加结构。

但不能改变核心科学含义。

## 答案扩展

如果资料答案过短，允许根据同一资料中的相关知识点进行补充，必须标记「答案扩展」。

如果超出资料范围：标记「外部补充」。

## 名词解释答案模板

```markdown
### 【标准答案】

XXX是指……。

其主要特点是……。

其核心意义/作用是……。
```

如果定义本身已经完整，不强行增加内容。

## 简答题答案模板

```markdown
### 【标准答案】

1. **概念：**
   ...

2. **机制/过程：**
   ...

3. **主要特点：**
   ...

4. **结果/意义：**
   ...
```

## 论述题答案模板

```markdown
### 【标准答案】

#### 一、基本概念

...

#### 二、主要过程/机制

...

#### 三、关键调控

...

#### 四、与其他过程的联系

...

#### 五、生物学意义

...
```

根据题目实际情况删除无关部分。

## 得分点

每道主观题必须单独生成得分点。得分点必须来自答案，不能为了凑数量添加无关内容。

例如：

```text
1. 正确定义
2. 关键酶
3. 反应方向
4. 调控机制
5. 生理意义
```

## 易错点

根据以下来源建立：

- 资料中反复强调的内容
- 真题容易混淆的知识
- 概念相近知识点
- 易混淆过程 / 酶 / 方向

例如：不要把竞争性抑制理解为降低 Vmax。
